# Contributing

Thanks for improving Discord Server Toolkit. Use a current Node.js LTS release, keep changes focused, and add behavioral tests for fixes and features.

Before opening a pull request, run `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`. Do not commit credentials, generated `dist` files, or dependency directories. By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
